Structured returns are the pipeline. The call is not.

What the PRA already runs

About 1,500 firms. Returns on a defined schedule, checked against defined fields.

What stays outside

Quarterly results: a curated presentation plus unscripted Q&A. Expensive to read properly, so the signal is not used systematically.

Two words
Leading: did the call move before the stress, not after. Alone: information the four reported lines do not already contain.

What we measure besides tone: was the answer direct, did it supply the metric, or did it change the subject. Positive and evasive can be the same sentence.

Say kappa, not 60%

Both methods reach for neutral, so raw agreement flatters them. FinBERT does something. The lexicon does not. They agree with each other about 58% of the time.

What we did not move

The 70% bar was set before coding. We published the miss. Directness is triage: where to look, not a judgement of a firm or a person.

Anachronism
The PRA did not exist before 2013. A category from today’s PRA sources, laid on a 2006 transcript, is anachronistic. The run is provisional for that reason.

Results · recommendations · Speaks: Taz

What the Bank should do with this

Use now

Run the pack when filings land. A person accepts or rejects watch, alert, or null. Keep the peer-quality gate. File a null in the same way as a watch.

Do not do

Do not promote the fine-tuned head. Do not add banks to make the peer gap look busier. Do not treat neutral as “no issue”.

Next analysis
Second coder on the 90-pair gold. Retag the four metrics inside the episode so the agree column is evidenced rather than n/a. Only then reopen promotion.
Limit
Eight turns is a print, not a population. Hedged answers still collapse toward neutral. That limit is on the note.
