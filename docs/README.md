## Rule of thumb

- **Google Doc** = words the whole team comments on  
- **Notebook** = analysis you run  
- **GitHub Project** = who owns what and by when  
- **Word/PDF** = what you submit  

Do not put the full report only in the notebook — hard for teammates to comment.
